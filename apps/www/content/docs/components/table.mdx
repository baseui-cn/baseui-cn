## API

### Table

| Prop                     | Type      | Default | Description                                                                                        |
| ------------------------ | --------- | ------- | -------------------------------------------------------------------------------------------------- |
| `disableScrollContainer` | `boolean` | —       | Render only `<table>` without the overflow wrapper — use when the parent already handles scrolling |

Table uses one row hierarchy with structural separators and restrained hover/selected surfaces. A surrounding Frame supplies the outer composition; Table does not add another card.

For manual installation, copy the stylesheet included with the component source and retain its import. CLI installation includes it automatically; website CSS is not required.
